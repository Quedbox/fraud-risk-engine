# fraud-risk-engine

## Что нужно разработать?
Система оценивания рисков при открытии банковских счетов

Нужно оценивать вводные данные на этапе подачи заявки(это самое важное - нельзя допустить утечку данных, которые возможно получить только постфактум)

### Три статуса, которые диктуются мерой уверенности в предсказании:
- Разрешить
- Отправить аналитику на валидацию
- Отказать

### Что нужно сделать?
1. Подготовить стабильное окружение, импортировать предполагаемые зависимости, создать venv
2. Скачать данные и сделать .gitignore, который будет закрывать реально ненужные файлы и директории
3. Провести базовый анализ в ноутбуке, зафиксировать выводы по графикам данных
4. Заранее рассмотреть признаки на потенциальный leakage
